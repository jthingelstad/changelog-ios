Changelog Versions icon design study
Saved 2026-11-01

Selected direction: three folded v marks stacked diagonally on ink navy,
representing successive versions and accumulated change. The primary uses
cobalt, tangerine and ivory. Release Notes uses the single folded v with
a period on cobalt, so the two apps share an identity and remain distinct.

icons/ contains the refined primary, Paper, Copper, Terminal and Afterglow,
each at full size and as a 60-pixel preview. The alternative editions are
intended for Supporting Members of the Weekly Thing.
explorations/ preserves the original Versions concept used for refinement.
prompts-and-manifest.json preserves the built-in ImageGen prompts and
identifies the local reference images for further exploration.

These are design concepts, not production assets installed in the app.
No code or existing active icons were changed. Files are saved locally;
this save does not commit, push, publish or deploy anything.
